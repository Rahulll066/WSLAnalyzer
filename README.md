# 🛡️ WSL Analyzer

WSL Analyzer is a web-based security analysis platform that analyzes Apache and Nginx access logs to detect suspicious activities, common web attacks, and reconnaissance attempts. It provides an interactive dashboard with threat summaries, attack visualizations, and actionable security insights.

---

## ✨ Features

### 📂 Log Upload

- Upload Apache or Nginx access logs
- Drag & Drop file upload
- Automatic log parsing and analysis

### 🔍 Threat Detection

Detects common web attacks including:

- SQL Injection (SQLi)
- Cross Site Scripting (XSS)
- Directory Traversal
- Command Injection
- Security Scanner Detection
- Brute Force Attempts

### 📊 Security Dashboard

Displays:

- Total Requests
- Suspicious Requests
- Risk Score
- Threat Level
- Most Common Attack
- Most Targeted Endpoint
- Security Recommendations

### 📈 Analytics

- Attack Distribution
- Threat Activity Timeline
- HTTP Status Code Distribution
- Top Attacking IPs
- Live Threat Feed
- Security Incidents

### 🚨 Incident Investigation

Detailed information for every detected threat:

- Source IP Address
- HTTP Method
- Target Endpoint
- Timestamp
- Attack Type
- Severity Level

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/WSLAnalyzer.git
```

---

## Backend Setup

```bash
cd backend
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the backend

```bash
uvicorn app:app --reload
```

Backend URL

```
http://localhost:8000
```

Swagger API Documentation

```
http://localhost:8000/docs
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend URL

```
http://localhost:5173
```

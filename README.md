# 🛡️ WSL Analyzer

**WSL Analyzer** is a web-based security analysis platform that analyzes Apache and Nginx access logs to detect suspicious activities, common web attacks, and reconnaissance attempts. It provides an interactive dashboard with threat summaries, attack visualizations, and actionable security insights.

---

## 📸 Preview

> Upload an Apache or Nginx access log and instantly visualize:
>
> - Threat Level
> - Risk Score
> - Attack Distribution
> - Threat Timeline
> - Top Attacking IPs
> - Security Incidents
> - Security Recommendations

---

## ✨ Features

### 📂 Log Upload

- Upload Apache or Nginx access logs
- Drag & Drop support
- Automatic log parsing

### 🔍 Threat Detection

Detects common web attacks including:

- SQL Injection (SQLi)
- Cross Site Scripting (XSS)
- Directory Traversal
- Command Injection
- Security Scanner Detection
- Brute Force Attempts

### 📊 Security Dashboard

Displays:

- Total Requests
- Suspicious Requests
- Risk Score
- Threat Level
- Most Common Attack
- Most Targeted Endpoint
- Security Recommendations

### 📈 Analytics

- Attack Distribution Chart
- Threat Activity Timeline
- HTTP Status Code Distribution
- Top Attacking IPs
- Live Threat Feed

### 🚨 Incident Investigation

View detailed information for each detected incident:

- Source IP
- HTTP Method
- Target URL
- Timestamp
- Attack Type
- Severity

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/WSLAnalyzer.git
```

---

## Backend Setup

```bash
cd backend

python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run server

```bash
uvicorn app:app --reload
```

Backend runs on

```
http://localhost:8000
```

Swagger UI

```
http://localhost:8000/docs
```

---

## Frontend Setup

```bash
cd frontend

npm install
```

Run

```bash
npm run dev
```

Frontend

```
http://localhost:5173
```
